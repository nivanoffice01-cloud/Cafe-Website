# AI-created menu category portraits

These 13 category portraits were created with OpenAI's built-in image generation tool for this project. They are editorial illustrations, not photographs of Mangosteen Cafe's exact dishes or plating.

Shared art direction: photorealistic premium cafe menu photography, 4:3 landscape composition, dark walnut table, softly blurred warm cafe interior, tungsten evening light, handmade stoneware, realistic food texture, no people, hands, logos, text, or watermarks.

The subject prompt was tailored to each category: shakes, juices, mocktails, iced tea, salad, pizza, burgers and sandwiches, breakfast, small plates, pasta, desserts, main course, and soup.
