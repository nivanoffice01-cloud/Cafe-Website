# Reservation illustration assets

These are decorative architectural illustration materials, **not photographs of
Mangosteen furniture or a reconstruction of its physical floor plan**. Genuine
café previews are loaded separately from the existing `/images/authentic/` set.
No generated venue interior is used.

Created with the built-in image-generation tool on 26 November 2026, then resized
and encoded with `cwebp -q 82` (chair quality 83). Alpha is preserved on the chair
and palm. The generated PNG originals remain in the user's Codex image library;
these optimized WebP files are the application assets.

- `cane-chair-v1.webp`: 256×256, transparent. A single decorative cane-back chair.
- `palm-v1.webp`: 384×384, transparent. One decorative top-down palm.
- `walnut-v1.webp`: 512×512, opaque. Decorative wood material for SVG patterns.

Prompts used (built-in tool, no CLI/API fallback):
