# Reservation photographic-style materials — v2

These are **decorative, generated furniture/material sprites**, not documentary
photographs of Mangosteen or a measured architectural model. The separate café
preview continues to use unchanged genuine photographs. No generated venue
interior, flattened seating-map image, Blender scene or heavy 3D model is used.

Created with the built-in image-generation tool on 26 November 2026. PNG originals
remain in the Codex image library. Optimized project assets are sibling WebP files;
v1 assets and the Git checkpoint remain recoverable. Preparation uses `cwebp -q 86`
with transparent-padding trimming and resizing. Transparency is retained for
furniture and plants. Exact output dimensions/source paths/bytes are recorded in
`artifacts/reservation-visual-refinement/assets.json`.

finish, furniture dimensions, species or planter positions of any named group.
The material scale is deliberately restrained relative to the unchanged tables.
