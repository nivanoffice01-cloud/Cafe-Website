# Responsive menu imagery

Optimized 320px and 800px WebP derivatives of existing project assets. Originals are unchanged.

- `category-*`: AI-generated category illustrations; provenance and original descriptions in `../menu-ai/README.md`. Displayed with “AI illustration” labels.
- `dish-*`: five existing licensed stock references; original Pexels links and licence notes in `../menu/README.md`. Displayed with “Reference photo” labels.

None is claimed to photograph a Mangosteen serving. Only the exact five named dishes with existing matched reference mappings receive dish photos. Remaining dishes retain neutral placeholders. Verified venue photography takes precedence in the digital-menu mapping.
