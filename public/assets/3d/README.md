# Future selective 3D assets

The current café journey uses real photographs and a WebGL camera. It loads no GLB models, and there is no physical menu-card model or menu-on-table interaction.

If a later food scene warrants authored 3D, place independently loadable assets here, for example food/hero-pizza.glb or food/coffee.glb.

Export in metres, Y-up, with applied transforms and PBR metallic-roughness materials. Use compressed geometry and web-sized textures. Load each food model only when that dish is selected. Photograph-matched scale, lighting, and materials are required before replacing any real café imagery.
